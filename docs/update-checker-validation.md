## Public releases and helper compatibility

Updates use anonymous GitHub release discovery; drafts, prereleases and private releases are excluded. The app never reads or sends GitHub credentials. At normal app/helper/CLI startup, migration attempts to delete only the generic Credential Manager target `RobloxMultiInstance/GitHubUpdates/LancePerdue23/roblox-multi-instance`. Missing credentials are harmless; deletion failures are logged and retried next startup. No other credentials or account settings are touched. Old prerelease preferences are ignored.

Publish one `vX.Y.Z` release per version with desktop setup, optional changed helper setup, portable archive and combined checksums/assets.json. Helper discovery also accepts historical `helper-vX.Y.Z` tags and selects the newest stable release containing a verified helper asset. App-only releases leave helper-only users on their latest applicable release. Historical releases remain intact.

Manifest `Version` identifies the installed edition. Optional `HelperVersion` pins helper and CLI executable versions; older manifests default it to `Version`. Protocol remains checked. App and helper versions may differ only with this explicit contract. Desktop update comparisons use the edition version. Setup still verifies every allowlisted payload hash, size, executable version and configured publisher pin.

`Package.ps1 -ExistingHelperPayload PATH` accepts a prior complete Helper payload with payload.json for an app-only release. Baseline hashes are verified; those helper/CLI files are embedded for fresh installs and upgrades. Identical installed files are retained. The shared core is compiled using the baseline version while desktop assemblies use the new app version. Shared runtime files must remain byte-identical; conflicting dependencies fail packaging and require a new helper package. Protocol compatibility alone does not establish binary compatibility. Verify app-only output with `scripts/testing/Test-Distribution.ps1 -AppOnly`. Isolated packaging checks can use `-ProductVersion` and `-Artifacts`; pass the matching `-ExpectedVersion` and `-Artifacts` to distribution verification. No new helper installer is emitted in this mode; assets.json and SHA256SUMS list only newly produced artifacts. Keep the README helper link pointing to the existing applicable release asset.

Missing public releases/assets, anonymous rate limits, offline requests, timeouts and cancellations have retry guidance. Cancellation removes partial downloads. Verification failure never enables setup. Handoff acknowledges acceptance, not successful installation. Canceled elevation, busy files and setup failures remain retryable. Windows installation acceptance remains pending; fixtures never install or stop Roblox.

## Manual Windows acceptance (pending)

Use a disposable Windows account. Check both installed editions, historical helper tags, a combined stable release, an app-only release with an unchanged helper, legacy installation upgrade, and a portable desktop. Verify edition versions and retained helper bytes after setup; test a fresh installation from the same app-only package.

Check startup notices, manual checks, no available release, offline requests, exhausted rate limits, timeouts, missing or duplicate edition assets, malformed metadata, untrusted redirect hosts, invalid digests, oversized/truncated payloads, publisher rejection, cancellation during transfer, and inaccessible staging folders. Every failed download must leave setup disabled and remove partial files. A failed check must invalidate the previous download offer. Release-page recovery must remain available.

Download explicitly, review notes as text, verify progress, cancel and retry. Setup must revalidate digest, size, executable version, edition/protocol and embedded allowlist. Configured publisher pins remain mandatory. Handoff validates parent identity and staged path, holds the verified setup file open against changes, waits for graceful closure, then rechecks configured publisher trust. Keep Roblox games open. Test busy files, declined elevation, setup failure and rollback. Acceptance of handoff must never claim installation success. Verify settings and browser integration survive.

Use normal and 150% display scaling and keyboard navigation. Ensure helper-only browser launches remain windowless and on demand. No fixture test performs installation or starts/stops Roblox. Nothing downloads or installs unattended.
