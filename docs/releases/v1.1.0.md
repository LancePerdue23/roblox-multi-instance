# v1.1.0 private validation prereleases

Windows x64, product version 1.1.0. The repository remains private. Repository collaborators can download these builds while signed into GitHub. Updates are manual for this testing round; the app's stable-only, unauthenticated update channel does not discover private prereleases.

## App + Helper — v1.1.0

- **Launch games** opens a compact launcher from every page: repeat the last setup, edit it, or create a new batch; review account order and layout before launching.
- Choose Grid, Columns, a saved layout, or leave windows alone. Follow actual progress and partial results; hiding the panel keeps the batch running, and canceling leaves started games open.
- **Stop all…** ends the listed verified Roblox clients, including background clients, after confirmation. This forcibly ends games and can lose unsaved progress. Newly opened clients are excluded from the confirmed list.
- Guided signup uses Roblox's official website. Users review and submit forms and complete security challenges themselves. Supplied credentials are protected locally with Windows CurrentUser encryption; interrupted signups can be recovered.
- Signed cosmetic recognition can be claimed by opening an eligible `.rmibadge` file and signing into Roblox. Badge issuer keys, eligibility lists and delivery files are not included in the release.
- Account creation, password controls, launch focus and automatic layouts have additional regression coverage.
- **Open Roblox app** remains available inside the launcher.

Choose `RobloxMultiInstance-Setup.exe` for the desktop workspace and matching helper. The portable ZIP includes the desktop and matching setup payload; it still needs the installed helper for launching and browser integration.

## Helper only — helper-v1.1.0

Choose `RobloxLaunchHelper-Setup.exe` for on-demand browser Play integration and `rmi` commands without the desktop workspace. This release includes the matching shared launch, operation-coordination and update-trust changes. Desktop signup, the launch panel and badge customization are features of the App + Helper edition.

## Install and verify

Download the installer for your existing edition and run it to upgrade. Settings and history are retained by the upgrade path. Switching editions requires uninstalling the current edition first. Do not install both editions side by side.

Each release contains only its applicable installer/portable files, SHA-256 sidecars, `SHA256SUMS.txt` and an edition-scoped `assets.json`. Verify a downloaded file with `Get-FileHash -Algorithm SHA256` and compare the result with its sidecar. These builds are unsigned; Windows may show Unknown publisher. Release checksums verify file integrity and do not independently identify a publisher.

Distribution builds omit debug symbols and normalize source paths. Package checks reject embedded developer user-profile paths in first-party desktop binaries.

## Testing scope and known limitations

Automated desktop, account, shared-service and package checks pass. The owner personally completed focused live checks for this private tester round. Broader isolated Windows installation/update, hardware, DPI and accessibility acceptance remains separate; these builds are prereleases.

Roblox's own **Minimize to tray on close** setting can cause closing one game to launch a tray replacement that affects other instances. Keep that setting off when testing independent window closure. This application does not replace Roblox's X-button behavior. See [closing multiple clients](../closing-multiple-clients.md).

Check the actual game and account before retrying an unconfirmed launch. Automatic layouts require verified account-to-window matching. Private-server links are unsupported. Optional reporting/payment services require separate configuration, and cosmetic recognition does not unlock features.
