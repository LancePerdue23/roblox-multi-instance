# Roblox Multi Instance v1.0.0

Published on October 31, 2026 as two separate validation prereleases at the owner's subsequent request, both targeting source commit `1d1594a4d1fad8f18cab14b6337c5daef2b02512`. The repository remains private. Stable production acceptance is pending.

- [Full app + helper v1.0.0](https://github.com/LancePerdue23/roblox-multi-instance/releases/tag/v1.0.0)
- [Helper-only v1.0.0](https://github.com/LancePerdue23/roblox-multi-instance/releases/tag/helper-v1.0.0)

Both are marked prerelease and neither is Latest. The helper-specific tag identifies its separate release page; both editions' executable versions remain 1.0.0.0. The updater deliberately ignores prereleases.

## Release notes

The first planned GitHub release includes the Windows x64 desktop app, an on-demand helper edition, and `rmi.exe` terminal commands.

- Desktop setup installs the React/WebView2 app, matching helper, and terminal commands.
- Helper setup includes the helper and terminal commands without desktop presentation or web assets. Browser launches are windowless and on demand.
- The portable ZIP includes the desktop, matching helper/CLI dependencies, and explicit graphical setup. Desktop startup does not install automatically.
- Shared services are separated from desktop presentation. Launch observation, readiness reporting, concurrent operation handling, and account lookup have reliability improvements.
- Setup and updates verify edition, protocol, payload allowlists, executable versions, sizes, and SHA-256 hashes. Installation and downloads remain explicit.

## Versions and compatibility

All current product assemblies and package metadata use 1.0.0 (Windows file version 1.0.0.0), helper protocol 1. The former 1.1.0 source number was unpublished development numbering; historical local 1.0.0/1.0.1 notes do not represent GitHub releases. Numeric update comparison fixtures deliberately retain synthetic 1.1.0/1.2.0 cases.

Numeric downgrade checks remain enforced for both modern and legacy installed helpers. Existing development installations numbered 1.0.1 or 1.1.0 require an explicit uninstall before installing 1.0.0. Uninstall can retain settings/history. Modern edition switching also requires uninstall first. Unknown installed versions fail closed. This transition still requires live acceptance; uninstall does not imply browser protocols or worker state were successfully verified.

## Assets

- `RobloxMultiInstance-Setup.exe`: desktop + helper + rmi.
- `RobloxLaunchHelper-Setup.exe`: helper + rmi, no desktop presentation.
- `RobloxMultiInstance-Portable.zip`: desktop payload and matching desktop setup.
- Three per-package `.sha256` sidecars, `SHA256SUMS.txt`, and `assets.json` (installer payload allowlists and portable metadata).

`SHA256SUMS.txt` covers the two installers, portable ZIP, and `assets.json`. Rebuilds may change hashes; use the acceptance record and final built manifest to identify the tested bytes. The Windows x64 desktop requires WebView2 Evergreen Runtime. The current updater uses unauthenticated GitHub requests; it cannot retrieve releases from this private repository. Manual downloads require repository access. Do not embed GitHub credentials in the app.
