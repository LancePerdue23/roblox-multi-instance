# v1.1.1 validation prereleases

Windows x64. The repository remains private. These unsigned validation builds are not a claim of completed clean-machine Windows acceptance.

- Setup logs now identify the attempt, build version, failing phase, first-party code locations, HRESULT, Windows native error codes, and bounded inner-error classifications. Exception messages, source paths and raw stack traces are excluded. Failures before rollback/cleanup are recorded before those steps can mask them. Setup names the log folder in its failure message.
- Private GitHub update access can be configured in System → Version & updates through a native Windows credential prompt. Tokens remain in Windows Credential Manager. Explicitly enable validation prereleases for this testing channel. See [setup instructions](../private-updates.md). Existing 1.1.0 installations need one manual download.
- New Alpha Tester, Bug Hunter, Contributor and Founder recognition artwork, animation scenes, collection controls, per-badge visibility/motion, and sidebar access. Recognition still requires a valid signed, account-eligible grant. Badges unlock no app features.
- New supporter badge designs, cumulative contribution changes and supporter service changes are excluded.

Download RobloxMultiInstance-Setup.exe for App + Helper. The portable ZIP includes the matching setup payload. The helper-v1.1.1 release contains the matching helper-only installer. Upgrade the existing edition; settings/history are retained. Do not install both editions side by side.

Setup failures are recorded in %ProgramFiles%\RobloxLaunchHelper\setup-logs\helper.log. Installed privileged verification may also write %ProgramFiles%\RobloxLaunchHelper\<Windows SID>\logs\helper.log; non-elevated errors use %LocalAppData%\RobloxLaunchHelper\logs\helper.log. Only logs from the new attempt diagnose the current failure. The friend's original failure is not claimed fixed until a fresh tester attempt identifies it.

Packages include SHA-256 sidecars, an edition-scoped assets.json and SHA256SUMS.txt. Builds are unsigned and may show Unknown publisher. Broader fresh-install/upgrade/uninstall, real private-account download, DPI and accessibility acceptance remains pending. No installation on the maintainer's account was used for validation.
