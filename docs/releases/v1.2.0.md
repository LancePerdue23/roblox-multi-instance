# v1.2.0 — unsigned validation prerelease

Windows x64. This release includes the current development features in fresh App + Helper, Helper only, and portable packages. The owner reports successful development-build testing. Packaged installation, upgrade, uninstall and real update handoff have not yet been verified; no isolated Windows test environment is available. These packages are provided for that next round of testing and are not a stable updater offer.

## Changes

- Account launches and batches use fixed status/error codes, redact provider details, and recover the batch gate even when cleanup fails. Background-client cleanup, launch startup/focus handling, and account controls include the latest fixes.
- Shortcut capture, validation, persistence, registration status and tray lifecycle include the current improvements. A shortcut already owned by another application is reported as unavailable.
- Recognition and supporter artwork, animations, combinations and tier progress include the current designs. Machine-local role switches and preview-only assets remain excluded.
- Robux support includes the approved pass catalog, cumulative credit across connected accounts, bounded inventory discovery, rate-limit handling and resumable verification. USD cumulative checkout, recovery and signed-receipt support are included in the source and desktop; Stripe payments remain unavailable until the separate service, public verification keys and sandbox acceptance are configured. Telemetry setup does not deploy that payment service.
- Optional technical error reporting uses the configured Cloudflare endpoint. It is off by default and sends only approved technical counters after user consent. Privacy controls can disable reporting and remove queued counters.
- Updates discover public stable releases anonymously, with explicit download/setup actions and edition, version, digest and payload validation. Old private update credentials are removed. Prereleases still require manual download; a private repository does not provide anonymous update access.
- Both installer options now share this release tag. Packaging includes the MIT license, manifests and checksum files, with public-release policies and Windows CI in the repository.

## Downloads and testing

- **RobloxMultiInstance-Setup.exe**: recommended App + Helper installation, including the `rmi` CLI.
- **RobloxLaunchHelper-Setup.exe**: Helper only with browser Play integration and the CLI, without the desktop workspace.
- **RobloxMultiInstance-Portable.zip**: desktop files plus the matching setup payload. Browser integration/helper maintenance still requires explicit setup.
- **assets.json**, **SHA256SUMS.txt**, and per-package **.sha256** files: version, payload and integrity metadata.

Downloading or extracting these packages does not replace the source checkout's `.build/desktop` development build. Running setup changes the installed edition; running a packaged app under the same Windows account can share settings, saved account profiles and helper integration with development. Portable is not an isolated data sandbox. Do not install both editions side by side; upgrade the current edition, and uninstall before switching editions.

These packages are intentionally unsigned, so Windows may show Unknown publisher. No certificate identity or signed acceptance is claimed. Repository visibility remains unchanged by this release. Full packaged Windows/Roblox acceptance and optional live Stripe service validation remain separate follow-ups.
